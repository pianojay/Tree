VAE on a 2D density — train in the browser, click to inspect likelihood & posterior

By Professor Minhyuk Sung, KAIST, created with Claude. Preserved as a reference for the independently developed Tree project.

Type an (unnormalized) density p(x,y) as a JavaScript expression in the box below. Samples are drawn from it and a 2D→2D VAE is trained on them, live. Click the data panel to pick x*: you get the likelihood p(x*|z), the true posterior p(z|x*), the encoder's q(z|x*), the ELBO and log p(x*). Click the latent panel to pick z*: the decoder distribution p(x|z*) is drawn in the data panel.

Click a point in the data panel.

log pθ(x*) is computed by numerically integrating p(x*|z)p(z) over the 2D latent grid, so the gap log pθ(x*) − ELBO(x*) equals KL(q(z|x*) ‖ p(z|x*)) exactly (up to grid error).
